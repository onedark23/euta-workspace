# ADR - 027 앱 아이콘

## 상태

채택 (2026-10-21). 패키징된 `euta.app` 아이콘 · 개발 모드(`pnpm dev`) Dock 아이콘 · euta cloud 웹 파비콘에 같은 도형을 쓴다.

## 맥락

- 패키징 설정(`scripts/package.mjs`)에 `icon` 이 없어 `euta.app` 에 Electron 기본 아이콘(`electron.icns`)이 들어갔다(ADR-014 한계).
- 사용자가 시안 10종 중 **E "사용자 + 커서"** 를 골랐다(PLAN 결정 "앱 아이콘").
- electron-builder 26.15.3 은 `icon` 에 SVG 를 받아 1024px 로 래스터화한 뒤 `.icns`·`.ico` 를 만든다(`app-builder-lib/out/util/iconConverter.js` · 공식 문서 "Icons & Images"). 절대 경로도 그대로 쓴다.
- 패키징은 projectDir = 스테이징(`release/stage`) 이라 앱 레포의 `build/` 를 자동으로 찾지 않는다(ADR-014).

## 결정

- 정본 = **`euta-app/build/icon.svg`** 하나(1024×1024 viewBox, 글자 없음 — 글꼴 의존 없이 래스터화). ICNS 는 레포에 두지 않는다.
- 패키징: `package.mjs` 의 electron-builder 설정에 `icon: <appDir>/build/icon.svg` 를 **절대 경로**로 넣는다. mac·win 공통.
- 개발 모드 Dock: Electron `nativeImage` 는 SVG 를 읽지 못한다(PNG·JPEG 만). 그래서 파생물 `build/icon.png`(512px)를 커밋하고, `pnpm icon`(`scripts/render-icon.mjs`, Playwright 로 SVG 래스터화)으로 다시 만든다. main 이 `!app.isPackaged` 일 때만 `app.dock?.setIcon()` 으로 건다(패키징본은 번들 icns 사용).
- euta cloud 웹: 별도 레포라 파일을 공유할 수 없어 `packages/web/public/favicon.svg` 에 사본을 둔다. 탭 아이콘은 작으므로 여백을 뺀 viewBox(`100 100 824 824`)로 자른다. `index.html` 에 `<link rel="icon" type="image/svg+xml">`.
- 도형: macOS 아이콘 격자(824px 둥근 사각형, 반지름 185, 여백 100) · 남색 그라디언트 `#2a3a66 → #121b36` · 흰 사람 실루엣 · 주황 커서 `#ff8a3d`.

## 이유

- SVG 하나면 크기별 산출물을 직접 만들고 관리할 필요가 없다. 도형만 쓰므로 어느 환경에서 래스터화해도 같다.
- 절대 경로는 스테이징 구조를 바꾸지 않고 앱 레포의 파일을 가리키는 가장 작은 변경이다.

## 고려한 대안

- **패키징에도 PNG 사용** — electron-builder 가 SVG 를 직접 받으므로 불필요. PNG 는 개발 모드 Dock 용으로만 둔다.
- **실행 중 SVG 를 래스터화(숨은 창 캡처)해 Dock 에 걸기** — 개발 편의 하나에 비해 코드가 크다. 제외.
- **`iconutil` 로 `.icns` 직접 생성** — mac 전용, 수작업 단계 추가. 제외.
- **`build/` 를 스테이징에 복사해 자동 탐색** — 복사 단계만 늘고 얻는 것이 없다. 제외.

## 결과

- 검증(2026-10-21, macOS arm64): `EUTA_PACKAGE_OUT=release/next pnpm package` 성공 → `euta.app/Contents/Resources/icon.icns`(16~1024px 11프레임) 생성, `Info.plist` `CFBundleIconFile = icon.icns`, ad-hoc 서명 검증·번들 CLI 해시 일치. 추출한 프레임을 눈으로 확인.
- 변환 도구: electron-builder 가 첫 실행 때 `icons-bundle.tar.gz` 를 내려받는다(이후 캐시). 패키징이 처음으로 네트워크를 쓰는 지점 — 오프라인 첫 패키징은 실패할 수 있다.
- 개발 모드 Dock · 웹 파비콘(2026-10-21): `pnpm icon` → `build/icon.png` 512px(투명 배경) 생성, 앱 typecheck · 단위 165 · E2E 5(개발 빌드) 통과. 웹 `vite build` → `dist/favicon.svg` 포함, `vite preview` 에서 `/favicon.svg` 200 `image/svg+xml` · 16/32px 렌더 확인. 서버는 `dist/` 를 정적 제공하므로 같은 경로로 나간다.
- 한계: `icon.svg` 를 고치면 `pnpm icon` 으로 PNG 를 다시 만들고, euta cloud 사본도 손으로 맞춰야 한다.
