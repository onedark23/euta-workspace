# PLAN - End-User 테스트 툴 종합 계획

> 상태: **구현 진행** — 단계 0~10 구현·자동 검증 완료 (2026-10-02). 수동 검증(OS 입력)·실사용 확인 대기. `미결` 항목은 사용자와 상의해 채운다.

## 배경

- 개발 단계 E2E 테스트만으로는 상용화 품질을 보장하기 어렵다.
- 실제 사용자가 쓰는 방식 그대로 서비스를 조작하고, 화면 변화와 결과물까지 검증하는 도구가 필요하다.

## 목표

- 실제 사용자처럼 웹앱/웹페이지를 조작(마우스·키보드·터치)하고, 화면 변화를 측정하고, 결과물을 분석한다.
- 특정 서비스에 묶이지 않는 범용 툴 — 테스트 스크립트만 바꿔 여러 SaaS 서비스를 테스트한다.
- 기본 모드(스크립트 자동화) 위에 전문 모드(AI 보조)를 얹는다.
- 정량 목표·성공 기준: `미결`

## 범위

| 구분 | 내용 |
|---|---|
| 포함 | 웹앱/웹페이지 테스트, SaaS 서비스 중심 |
| 플랫폼 | macOS · Windows · **Linux**(x64 데스크톱, 2026-10-30 추가) |
| 클라우드 웹 | **euta cloud** — 로컬에서 만든 스크립트를 등록해 즉시·예약 실행, 팀 공유 이력 (AI 없음) → [PLAN_euta-cloud](PLAN_euta-cloud.md) |
| 제외 (이번 단계) | 네이티브 앱. 그 밖의 제외 범위 `미결` (데스크톱 앱 사내 배포는 단계 17로 포함, 2026-10-30) |

## 요구사항 (사용자 제시)

| 배포 전제 — Apple Developer 계정(확인 중) · Windows · Linux 실기 확인 | 맥 자동 설치 불가 · Windows · Linux 미검증 · 허용된 IP 에서만 접속(ingress 허용 목록, 외부 DNS 2026-10-30 등록) | 계정 전엔 맥은 알림 + 내려받기, Windows · Linux 는 실기 설치·실행 1회 확인 후 배포 |
| 구독 사용량 전제("ordinary, individual usage") | 무인 대량 AI 판정에 구독 부적합 | 대량 판정은 API 키 경로로 2단계 설계 |
| 네이티브 모듈(pty·SQLite·OS 입력) Electron 재빌드 | 앱 단계 지연 | 앱을 마지막 단계로, 대안 라이브러리는 ADR |
| OS 입력 권한 | 무인 검증 불가 | 선택 어댑터로 분리, 수동 검증 |
| 결과물(HAR·스크린샷)에 secrets 유출 | 보안 사고 | 마스킹을 엔진 필수 기능으로(ARCH 보안 절) |
| 영상·trace 스크린캐스트는 마스킹 불가 | 화면에 다시 표시된 secret 이 녹화에 남음 | 민감 계정은 `record.video: false`, 스텝 `mask` 지정 ([ADR-006](../40.설계/ADR_006_secrets-마스킹.md)) |
| AI 가 `${secrets.X}` 를 외부 URL 로 보내는 경로 | 프롬프트 인젝션 시 secret 유출 | 미해결 — DSL 변경 필요(허용 도메인 등). 실사이트 테스트 전 결정 필요 |
| 봇 탐지 서비스 | 브라우저 입력 차단 | 스텝 단위 OS 입력 전환 |
